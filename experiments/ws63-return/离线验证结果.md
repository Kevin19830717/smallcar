# 离线验证结果

2026 年 11 月 11 日。

## C 端

用海思 fbb_ws63 公开 SDK 的真实头文件检查接口。SDK 对应提交为 3bed8deab33748895528f80768dce42f03a18e6b。用 Zig 的 C 编译前端在本机编译三个源文件，开启 Wall、Wextra、Werror，三个文件通过。此项未执行 WS63 固件的完整链接。

C 编解码测试通过，包含 18 字节小端序逐字节对照、负 RSSI 还原、版本和长度错误拒绝。

C 回传客户端状态机的模拟回调测试通过，包含扫描、停止扫描后建链、MTU 交换、属性发现、恢复扫描、发送确认、断线后重连重发同一帧，以及 128 条队列满后计数。模拟回调执行源码本身，协议栈和无线设备由测试桩代替。

## 基站电脑端

collect_base.py 已验证正常解析、重复去重、坏字段拒绝、新会话区分和分段串口消息拼接。

simulate_return.py 本机服务器完成 7 类检查，554 条唯一样本落盘，50 条重复帧去重。还验证了数据库提交后主动丢确认、客户端重连重发，以及数据库关闭重开后的去重。

性能记录见同目录的模拟测试结果.json。运行时使用本机 HTTP 代替 SLE。延迟包含本机请求、SQLite 提交和确认，不能用于推断 WS63 无线延迟或空口吞吐。
