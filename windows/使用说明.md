# 一键启动小车

将整个文件夹复制到新的 Windows 10/11 电脑并解压到可写目录。无需虚拟机、ROS、Python；需要 Windows 的 OpenSSH 客户端。没有 ssh 时在“设置→应用→可选功能→添加功能”安装 OpenSSH 客户端；验证：终端输入 `ssh -V` 能显示版本。

连接对应小车 Wi-Fi 后，双击“启动425小车.cmd”或“启动1003小车.cmd”。首次连接核对 SSH 指纹，输入 yes；输入小车密码，通常 <robot-password>，输入不显示字符。不会把密码写入包里。后续仍需输入一次 SSH 密码；SSH 密钥登录需要单独配置，本包没有修改认证设置。

脚本先 ping，再 SSH 检查。网页已运行则直接复用，正在巡航也不重启；未启动且无冲突进程才启动导航和网页。检测到已有底盘、导航或建图但网页不可用，则停止并显示错误，避免双控制器竞争。检测与启动用锁避免两个脚本同时启动。最后自动打开 `http://192.168.0.100:8890/`，不会启动巡航、初始化桩位或发送速度。

425 使用 `~/r550_field_kit/kit nav`；1003 使用 `~/lab_cruise_ws/demo/start_demo.sh`。目标路径不同，不要选错。地址变化可在 PowerShell 执行 `./Start-Robot.ps1 -RobotProfile 425 -RobotAddress 新IP`。

运行已启动的导航可能造成底盘串口争用、速度指令竞争、重复定位或定位重置；本包遇到不明确的半启动状态会拒绝叠加启动，不会自动杀进程。远端启动日志：`~/.cache/r550_start.log`。若网页仍打不开：检查脚本错误、在电脑执行 `Test-NetConnection 192.168.0.100 -Port 8890`；TcpTestSucceeded=True 表明网页端口可达。

主机指纹按1003/425分别保存。遇到指纹变化先确认是否换车或重装，不要随意删除校验文件。请把整个文件夹一起复制，不要只复制cmd。

验证范围：PowerShell/Python语法，以及1003现有服务复用分支；425当前未连接，冷启动分支需在425实车上首次使用时验证。启动不会自动完成定位，打开网页后仍需核对地图位置及朝向。
